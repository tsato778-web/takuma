# ワイヤーフレーム（主要画面）

美容クリニック/美容室系の落ち着いた UI。各 UI 要素にデータ源を明記し、`schema.prisma` との整合を担保する。

---

## 1. 予約台帳（横型タイムライン）

縦軸=時間、横軸=スタッフ（or 席）。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ リピスト   [渋谷店 ▼]        2026/05/27 (水)  ◀ 今日 ▶   [日|週]  ＋新規予約  🔍 │ ← store切替=storeId
├──────────────────────────────────────────────────────────────────────────────┤
│ 本日 予約12 / 来店3 / 未会計2 / No-show0          再来率 68%    売上 ¥184,000   │ ← サマリ
├────────┬──────────────┬──────────────┬──────────────┬──────────────┬──────────┤
│ 時間   │ 田中(指名可) │ 佐藤         │ 鈴木         │ [個室A]      │ [席1]    │ ← Staff/Resource列
├────────┼──────────────┼──────────────┼──────────────┼──────────────┼──────────┤
│ 10:00  │┌────────────┐│              │              │              │          │
│ 10:30  ││★山田花子   ││┌───────────┐│              │              │          │ ★=指名
│ 11:00  ││ カット+カラー│││ 高橋健    ││              │              │          │
│ 11:30  ││ 🎫残3 🏷VIP││└───────────┘│              │              │          │ 🎫=回数券残 🏷=タグ
│ 12:00  │└────────────┘│              │┌───────────┐ │              │          │
│ 12:30  │              │              ││⚠LINE未追加││              │          │ ⚠=LINE未連携
│ 13:00  │┌────────────┐│              ││ 伊藤(新規)││              │          │
│ 13:30  ││💰未会計    ││              │└───────────┘ │              │          │ 💰=未会計(要レジ)
│ 14:00  ││ 中村ゆい   ││              │              │              │          │
│ 14:30  │└────────────┘│              │              │              │          │
└────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────┘
   ↑ 予約ブロックは D&D で時間移動 / 列間移動(担当変更) / 端ドラッグで時間延長
```

| UI 表示 | データ源 |
|---|---|
| ★ 指名 | `Reservation.isNominated` / `staffId` |
| 🎫 残数 | `CustomerTicket.remaining`（対象メニュー一致分の合計）|
| 🏷 タグ | `Customer.tags[]` |
| ⚠ LINE未追加 | `Customer.lineLink == null` |
| 💰 未会計 | `Visit` 有 かつ `Sale.status != CLOSED` |
| 色 | `Staff.color` |
| ステータス枠線 | `Reservation.status`（仮=点線, 確定=実線, 来店=塗り, no-show=赤）|

**D&D 挙動**: 時間移動→`startAt/endAt` 更新（衝突チェック）、列間移動→`staffId`/`resourceId` 変更、端ドラッグ→`endAt` 延長。新規はカレンダー空白を範囲ドラッグ→顧客検索→メニュー選択。
> パフォーマンスとバッジの一括取得は [design/availability-search.md](./design/availability-search.md) を参照。

## 2. 会計（レジ）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 会計  ─  山田花子 様  🎫カット回数券 残3   2026/05/27 来店 (担当: 田中)         │
├───────────────────────────────────┬──────────────────────────────────────────┤
│ 明細                              │ 商品/メニュー追加                          │
│ ① カット            ¥4,000 田中  │ [カット][カラー][トリートメント] ...       │
│ ② カラー            ¥6,000 田中  │ [シャンプー物販][ヘアオイル] ...           │
│ ③ カット回数券 消化   ¥0   🎫-1   │ 🎫 回数券を消化   [カット回数券 残3 ▼]    │ ← TICKET_USE(amount0)
│ ④ ヘアオイル(物販)   ¥3,200       │ 🎁 回数券を販売   [10回券 ¥40,000]        │ ← TICKET_SALE(売上計上)
│ ─────────────────────────────────│ [割引適用 ▼]  クーポン / 手動値引き        │
│ 小計            ¥13,200          │                                          │
│ 割引            −¥1,000          │                                          │
│ 消費税(内税)     ¥1,109          │                                          │
│ 請求総額        ¥12,200          │                                          │
├───────────────────────────────────┴──────────────────────────────────────────┤
│ お支払い（複数可）                                                            │
│ │ 現金 ¥2,200 │ カード ¥10,000 │ ＋支払追加 │   入金合計 ¥12,200  不足 ¥0 ✓  │ ← Σpayment=total
│ [現金][カード][LINE Pay][回数券][プリペイド]                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 本日:消化売上 ¥6,000   現金売上 ¥2,200   総売上 ¥12,200   未消化残高 ¥80,000  │
│                                                  [会計を確定する] [保留]       │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 指標 | 算出 |
|---|---|
| 消化売上 | この会計の `TicketUsage.unitValue × usedCount`（総売上には含めない管理値）|
| 総売上 | `Sale.total`（日次は `Σ Sale.total`）|
| 未消化残高 | 当該顧客 `Σ CustomerTicket.remaining × unitValue`（前受け残）|
| 入金合計 | `Σ Payment.amount`、`= total` で確定可 |

確定トランザクションの詳細は [design/accounting.md](./design/accounting.md) / [design/ticket-logic.md](./design/ticket-logic.md)。

## 4. LINE チャット

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ LINE [渋谷店 ▼]                          [トーク] [配信(セグメント)] [テンプレ] │
├───────────────────────┬──────────────────────────────────────────────────────┤
│ トーク一覧            │ 山田花子 様  🏷VIP  🎫残3   [カルテ][予約作成]        │ ← 顧客と紐付
│ ● 山田花子   13:20    │                          予約ありがとうございます🌸 ▶│ ← push(自動)
│   予約変更したい...   │                              5/27 11:00 確定しました   │
│   中村ゆい   昨日      │ ◀ 予約変更したいのですが                              │ ← Webhook受信
│ ⚠伊藤(未連携)         │ ◀ 来週は空いてますか？                                │
│ [セグメント:失客30日] │ [メッセージ入力...]            [テンプレ▼] [送信]      │
└───────────────────────┴──────────────────────────────────────────────────────┘

▼ 配信(セグメント)タブ
┌──────────────────────────────────────────────────────────────────────────────┐
│ セグメント条件: 最終来店30日以上 AND 回数券残>0 AND LINE連携済   → 対象 42名   │
│ テンプレ:「お久しぶりです。回数券の期限が近づいています…」 [予約ボタン付与]   │
│ 配信: ○即時 ●予約 [2026/05/28 10:00]                       [配信予約する]     │
└──────────────────────────────────────────────────────────────────────────────┘
```

| UI | データ源 |
|---|---|
| トーク相手 | `LineLink → Customer`（`lineUserId` 突合）|
| 受信メッセージ | LINE Webhook → 保存 |
| 送信(自動/手動) | `MessageLog`（trigger は `ReminderRule`）|
| セグメント条件 | `Campaign.segmentJson`（[design/segment-dsl.md](./design/segment-dsl.md)）|
| ⚠ 未連携 | `LineLink == null` の顧客は配信対象外 |

## 5. KPI ダッシュボード

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ KPI分析 [渋谷店 ▼ / 全店]        期間 [2026/05 ▼]              [CSVエクスポート]│
├──────────────┬──────────────┬──────────────┬──────────────┬───────────────────┤
│ 再来率        │ 新規→再来    │ 失客率        │ 客単価        │ LTV(平均)         │
│ 68% ▲3pt     │ 42% ▲1pt     │ 12% ▼2pt     │ ¥9,800       │ ¥58,000           │ ← kpi_daily集計
├──────────────┴──────────────┴──────────────┴──────────────┴───────────────────┤
│ ■ 再来率トレンド(月次)  60→62→65→68%   ■ コホート(初回月別 継続率)            │
│ ■ 失客アラート(要フォロー)             ■ スタッフ別売上/指名率                 │
│   伊藤さくら 最終132日 🎫残0 [LINE配信]   田中 ¥420,000 指名62%               │
│   高橋健    最終88日  🎫残1 [LINE配信]   佐藤 ¥310,000 指名40%               │
│ ■ 回数券消化状況  販売58枚 / 消化率73% / 未消化残高 ¥1,240,000               │
└──────────────────────────────────────────────────────────────────────────────┘
```

| KPI | 算出（[design/kpi-aggregation.md](./design/kpi-aggregation.md)）|
|---|---|
| 再来率 | `repeatCustomers / visits`（期間）|
| 新規→再来 | 初回顧客のうち2回目来店した割合（`firstVisitAt` コホート）|
| 失客率 | `status=DORMANT/LOST` 割合 |
| 客単価 | `Σ Sale.total / Σ Visit` |
| LTV | 顧客別 `Σ Sale.total` の平均 |
| スタッフ別売上/指名 | `SaleItem.staffId` 集計 / `Reservation.isNominated` 比率 |
| 回数券消化率/未消化残高 | `TicketUsage` / `CustomerTicket.remaining` |
| 全店切替 | OWNER のみ、`storeId` フィルタ解除して横断集計 |
