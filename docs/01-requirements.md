# NAORU技術アカデミー 会員サイトMVP 要件定義

## 1. プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| プロダクト名 | NAORU技術アカデミー 会員サイト（仮称） |
| 目的 | 治療家・施術者向けに、動画講座・月1ライブ・症例相談を提供するオンライン学習プラットフォームを構築する |
| MVPゴール | サブスク会員が「学ぶ → 疑問を解消する → 実践する」ループを1本の導線で回せる状態を作る |
| リリース想定 | 初回3〜4ヶ月でクローズドβ、6ヶ月目に有料公開 |
| 課金モデル | Stripeによる月額サブスクリプション（プランはStandard 1つ + 年払いオプション） |

## 2. ターゲットユーザー

- **プライマリ**: 整体・カイロ・整骨院などの現役施術者（20代後半〜50代）
- **セカンダリ**: 施術系の学生、独立準備中の若手
- **利用シーン**: 診療後の夜〜週末に、スマホ・PC・タブレットで視聴

## 3. 提供機能（MVPスコープ）

| # | 機能 | 概要 | MVP必須 |
| --- | --- | --- | --- |
| F-01 | 会員登録・ログイン | メール+パスワード / Google OAuth。Supabase Auth。 | ✅ |
| F-02 | サブスク課金 | Stripe Checkout + Customer Portal。プラン: Monthly / Yearly。 | ✅ |
| F-03 | コース一覧 | 公開中コースを一覧・カテゴリ絞り込み・検索 | ✅ |
| F-04 | コース詳細 / 動画視聴 | Vimeoプレイヤー埋め込み。章立てに沿った視聴。 | ✅ |
| F-05 | 学習進捗管理 | 視聴済み判定（90%以上）、コースごとの進捗％、続きから再生 | ✅ |
| F-06 | 月1ライブページ | 次回ライブ告知、Zoom/Vimeo Live URL、アーカイブ動画掲載 | ✅ |
| F-07 | 症例相談掲示板 | スレッド形式。投稿・返信・添付画像（Supabase Storage） | ✅ |
| F-08 | AI関連動画レコメンド | 視聴中/直近の視聴レッスンに対して、OpenAI Embeddings + pgvectorで類似レッスンを3件提示 | ✅ |
| F-09 | プロフィール / 通知設定 | 氏名・所属・アイコン、メール通知ON/OFF | ✅ |
| F-10 | 管理画面（軽量） | 講座・レッスン・ライブの登録編集。CSVインポートは対象外。 | ✅ |

### スコープ外（フェーズ2以降）
- モバイルアプリ、オフライン視聴、認定試験、ポイント/バッジ、アフィリエイト
- チーム/法人プラン、複数拠点請求
- ライブ配信の内製化（当面はZoom / Vimeo Liveで代替）

## 4. 非機能要件

| 分類 | 要件 |
| --- | --- |
| 性能 | 主要ページ TTFB < 500ms（Vercel Edge / ISR）、動画再生開始 < 3s |
| 可用性 | Vercel + Supabase Hobby/Proで99.5% |
| セキュリティ | Supabase RLSで会員データを保護。Stripe webhookは署名検証。動画URLはVimeoのドメイン制限で直リン防止。 |
| プライバシー | 個人情報は最小限。特商法/プライバシーポリシー/利用規約を掲載。 |
| アクセシビリティ | 主要導線はキーボード操作可、コントラスト AA相当 |
| 対応環境 | 最新Chrome/Safari/Edge/Firefox、iOS15+、Android10+ |
| 多言語 | 日本語のみ（i18n設計は残す） |
| 監査 | 主要操作（ログイン・課金・投稿）はSupabaseのaudit_logテーブルに残す |

## 5. 権限ロール

| ロール | 権限 |
| --- | --- |
| guest | LP・料金・特商法閲覧のみ |
| free | 登録済み・未課金。プレビュー動画のみ視聴可 |
| member | サブスク有効。全動画・掲示板・ライブ・AI推薦を利用可 |
| admin | 管理画面フルアクセス。会員一覧の閲覧、コンテンツCRUD |

## 6. 外部サービス構成

| 用途 | サービス | 備考 |
| --- | --- | --- |
| ホスティング | Vercel | Next.js App Router + Edge Runtime |
| DB / Auth / Storage | Supabase | Postgres 15、Auth、Storage、pgvector拡張 |
| 課金 | Stripe | Checkout / Billing Portal / Webhook |
| 動画配信 | Vimeo Pro or Premium | Private with domain restriction |
| AI | OpenAI API | `text-embedding-3-small` + `gpt-4o-mini` |
| メール | Resend（Supabase SMTP経由も可） | 通知・領収書 |
| 監視 | Vercel Analytics + Sentry | エラー・パフォーマンス |

## 7. リスクと前提

- Vimeoの契約プランがドメイン制限に対応していることを確認する
- Stripe請求書の日本語カスタム項目（適格請求書番号）はメタデータで持つ
- 掲示板の医療系相談は「診断ではない」旨の免責を必ず表示
- OpenAI利用ログは学習に使われないAPI（`OPENAI_API_KEY`のBusinessプラン）を推奨
